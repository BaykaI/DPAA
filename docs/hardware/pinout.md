# Распиновка

## Основная плата: Colorlight i9 + плата расширения

Порты верхнего уровня — `gateware/rtl/top_colorlight_i9.v`, ограничения —
`gateware/colorlight_i9_dpaa.lpf`. В шаблоне все выводы стоят как `SITE "???"`:
их нужно заполнить по распиновке платы расширения i9 v7.2 (таблица PMOD P1–P6 из
документации платы у продавца или в проектах сообщества Colorlight i5/i9). Пока
остаётся хоть одна заглушка, `make` откажется собирать битстрим — это защита от
неверной распиновки.

| Порт | Направление | Сигнал | Разъём (контакты — в [wiring.md](wiring.md)) |
|---|---|---|---|
| `clk25` | вход | генератор 25 МГц модуля i9 | (на модуле) |
| `led` | выход | «сердцебиение» ≈ 1.5 Гц | (светодиод модуля) |
| `bclk`, `lrclk`, `mon_sd` | выход | такты I2S, ЦАП наушников | P1 |
| `esp_tx`, `esp_rx` | выход / вход | UART к ESP32-S3 (1 Мбод) | P1 |
| `txd[0..15]` | выход | данные усилителей 1–16 | P2, P3 |
| `rxd[0..15]` | вход | микрофоны 1–16 | P4, P5 |
| `rxd[16]` | вход | калибровочный зонд | P6 |
| `usb_tx`, `usb_rx` | выход / вход | UART к ноутбуку (USB-UART DAPLink или адаптер CP2102 на J28) | P1 или линии DAPLink |
| `btn_test` | вход | кнопка SW1 «тестовый тон» на распределительной плате | P1 |

Проверьте по документации платы, выведен ли USB-UART отладчика DAPLink на выводы ПЛИС.
Если нет, подключите к `usb_tx`/`usb_rx` копеечный адаптер CP2102/CH340 (3.3 В).
Загрузка прошивки идёт через DAPLink: `make prog` (`openFPGALoader -c cmsisdap`).

ESP32-S3 соединяется с ПЛИС тремя проводами: GPIO TX → `esp_rx`, GPIO RX ← `esp_tx`, GND.
Питание ESP32 — от своего USB. Прошивка ESP32 не зависит от ПЛИС: в отличие от ULX3S,
её не нужно перепрошивать через ПЛИС.

## Альтернатива: ULX3S

### Порты ПЛИС (ULX3S)

Имена портов совпадают с официальным файлом ограничений ULX3S, поэтому номера
выводов кристалла берутся оттуда, а не придумываются: скачайте `ulx3s_v20.lpf` из
документации ULX3S (репозиторий платы, каталог с файлами ограничений) и положите в
`gateware/`. `make` объединит его с `ulx3s_dpaa_io.lpf` (настройки буферов).

| Порт | Направление | Сигнал | Куда |
|---|---|---|---|
| `clk_25mhz` | вход | генератор 25 МГц | PLL → 50 МГц |
| `gp[0]` | выход | BCLK 3.125 МГц | U1, U2, U9 распред. платы |
| `gp[1]` | выход | LRCLK 48.828 кГц | U3, U4, U9 |
| `gp[2]` … `gp[17]` | выход | TXD0 … TXD15 | U5, U6 → элементы 1–16 |
| `gp[18]` | выход | MON_SD | ЦАП наушников PCM5102A |
| `gn[0]` … `gn[15]` | вход | MIC0 … MIC15 | U7, U8 ← элементы 1–16 |
| `gn[16]` | вход | CAL | калибровочный зонд |
| `gp[19..27]`, `gn[17..27]` | — | свободны (Z) | резерв: вторая решётка, датчики |
| `ftdi_txd` / `ftdi_rxd` | вход / выход | UART к ноутбуку | USB-разъём US1 ULX3S |
| `wifi_txd` / `wifi_rxd` | вход / выход | UART к ESP32 | встроенный ESP32 |
| `wifi_en`, `wifi_gpio0` | выход | = 1 | ESP32 включён, обычная загрузка |
| `btn[1]` (FIRE1) | вход | тестовый тон | пока нажата — тон 3 кГц по нормали |
| `led[7:0]` | выход | индикация | 0 — «сердцебиение», 1 — излучение, 2 — приём, 3 — команды UART, 4–7 — уровень микрофона 1 |

Перед первым включением сверьте по схеме своей ревизии ULX3S:
* на какие контакты разъёмов J1/J2 выведены gp/gn 0–18 (нумерация на шелкографии платы);
* активный уровень кнопки FIRE1 (в проекте — активная «1»);
* что gp/gn 0–18 не заняты перемычками/периферией в вашей ревизии.

При другой раскладке правится только `gateware/rtl/top_ulx3s.v` (назначение сигналов
на gp/gn) и таблица в [schematics.md](schematics.md).

**ESP32 и прошивка ПЛИС.** Пока в ПЛИС загружен этот проект, UART ESP32 занят
командами, поэтому саму ESP32 прошивайте, предварительно загрузив в ПЛИС стандартный
«passthru»-битстрим ULX3S (обычная процедура для этой платы), затем вернитесь к
`make prog`.

## Шлейф «распределительная плата ↔ модуль» (IDC 2×5)

| Контакт | Сигнал | Контакт | Сигнал |
|---|---|---|---|
| 1 | +5 В | 2 | +5 В |
| 3 | GND | 4 | BCLK |
| 5 | GND | 6 | LRCLK |
| 7 | GND | 8 | TXD (данные усилителя) |
| 9 | GND | 10 | RXD (данные микрофона) |

Номер элемента = номер разъёма J1…J16 = позиция в решётке слева направо, если
стоять за решёткой лицом по направлению излучения (положительные углы — вправо).

## Кабель калибровочного зонда (RJ45, T568B)

| Пара | Контакты | Сигнал |
|---|---|---|
| 1 | 1–2 | BCLK / GND |
| 2 | 3–6 | LRCLK / GND |
| 3 | 4–5 | +5 В / +5 В |
| 4 | 7–8 | SD / GND |
