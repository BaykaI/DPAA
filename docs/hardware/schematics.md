# Схемы (теоретическая проработка)

**Принцип: максимум готовых модулей, минимум ручного монтажа.** Своя плата в установке
одна — **распределительная (A3)**, и её собирает фабрика (SMT + выводной монтаж). Всё
остальное — готовые модули, которые соединяются проводами Dupont «мама–мама»
и готовыми шлейфами: без обжима и без пайки. Паять вручную остаётся только штыревые
гребёнки модулей, если продавец присылает их отдельно, и провода динамиков.

Механика элемента — [mechanics.md](mechanics.md), соединения устройств —
[wiring.md](wiring.md). Все логические сигналы — LVCMOS 3.3 В.

---

## 1. Элемент решётки (16 шт.) — только готовые модули

```
   A3: разъём Jn (2×6)          провода Dupont F–F, 30–40 см
   нечётный ряд  ── 1 +5V  ──────────────► VIN  ┐
                 ── 3 GND  ──────────────► GND  │ A6.1 модуль MAX98357A
                 ── 5 BCLK ──────────────► BCLK │ (ЦАП + усилитель класса D)
                 ── 7 LRCLK ─────────────► LRC  │ GAIN, SD — не подключать
                 ── 9 TXD  ──────────────► DIN  ┘ OUT+/OUT− → BA1 динамик
   чётный ряд    ── 2 +3.3V ─────────────► VDD  ┐
                 ── 4 GND  ──────────────► GND  │ A6.2 модуль ICS-43434
                 ── 6 BCLK ──────────────► SCK  │ (микрофон с АЦП 24 бит)
                 ── 8 LRCLK ─────────────► WS   │
                 ── 10 RXD ◄───────────── SD   │
                 ── 12 GND ──────────────► L/R  ┘ (левый слот)
                    11 — GND, резерв
```

| Модуль | Вывод | Откуда | Примечание |
|---|---|---|---|
| A6.1 MAX98357A | VIN | Jn.1 (+5 В) | ток до ~0.5 А в пиках — один провод Dupont достаточен |
| | GND | Jn.3 | |
| | BCLK | Jn.5 | свой выход буфера на A3 |
| | LRC | Jn.7 | свой выход буфера на A3 |
| | DIN | Jn.9 | данные элемента n |
| | GAIN | не подключать | усиление 9 дБ; громкость задаётся цифрой в ПЛИС |
| | SD | не подключать | модуль включён; режим L/R не важен — в оба слота идёт одно и то же |
| | OUT+, OUT− | динамик BA1 | 2 провода (у модуля Adafruit — винтовая колодка) |
| A6.2 ICS-43434 | VDD | Jn.2 (+3.3 В) | чистое 3.3 В с отдельного стабилизатора U21 на A3 |
| | GND | Jn.4 | |
| | SCK | Jn.6 | свой выход буфера на A3 |
| | WS | Jn.8 | свой выход буфера на A3 |
| | SD | Jn.10 | на A3: 100 кОм к земле, буфер к ПЛИС |
| | L/R | Jn.12 (GND) | левый слот |

Порядок выводов на гребёнках модулей у разных продавцов разный — подключайте **по
надписям на модуле**, а не по положению штырьков.

## 2. Распределительная плата A3 (единственная своя плата, собирается фабрикой)

Задачи: размножить такты (по отдельному выходу буфера на каждую нагрузку), буферизовать
все линии (защита выводов ПЛИС), раздать 5 В с предохранителями и чистое 3.3 В
микрофонам, вывести два луча приёма в наушники.

```
 Плата ПЛИС: PMOD P1–P6 → J19–J24 (шлейфы W1–W6)
 BCLK ──[U1–U4 74LVC244]── 32 × 33 Ом ──► Jn.5 (усилители), Jn.6 (микрофоны)
 LRCLK ─[U5–U8 74LVC244]── 32 × 33 Ом ──► Jn.7, Jn.8
 TXD0–15 ─[U9, U10]─────── 16 × 33 Ом ──► Jn.9
 MIC0–15 ◄─33 Ом─[U11, U12]◄─ 100k↓ ──── Jn.10
 MON_SD, BCLK, LRCLK ─[U13]──► U31 PCM5102A ─► U32 TDA1308 ─► J26, J27 (наушники)
 BCLK, LRCLK ─[U13]──► J17 RJ45 (зонд);  CAL ◄─[U13]◄── J17
 ESP_TX/RX ↔ 100 Ом ↔ J25;  USB_TX/RX ↔ 100 Ом ↔ J28;  SW1 → BTN_TEST

 +5V (J18) → Q1 → D1 TVS → C 1000 мкФ → F1–F4 (PTC 1.5 А, по 4 элемента) → Jn.1
           → U20 AP2112K-3.3 → 3V3_LOGIC (буферы U1–U13, U31)
           → FB1 → U21 AP2112K-3.3 → 3V3_MIC → Jn.2 (16 микрофонов), J17 (зонд)
           → U32 TDA1308 (5 В)
```

### Разъём элемента Jn (J1–J16): штыревой 2×6, шаг 2.54 мм

| Контакт | Цепь | Контакт | Цепь |
|---|---|---|---|
| 1 | +5 В (через F1–F4) | 2 | +3.3 В (3V3_MIC) |
| 3 | GND | 4 | GND |
| 5 | BCLK усилителя | 6 | BCLK (SCK) микрофона |
| 7 | LRCLK усилителя | 8 | LRCLK (WS) микрофона |
| 9 | TXD n | 10 | RXD n (SD микрофона) |
| 11 | GND (резерв) | 12 | GND (для L/R микрофона) |

Нечётный ряд — к усилителю, чётный — к микрофону: провода из одного ряда идут к одному
модулю, перепутать трудно.

### Буферы

| Буфер | Входы | Выходы (каждый через 33 Ом) |
|---|---|---|
| U1, U2 | BCLK | Jn.5, n = 1…16 |
| U3, U4 | BCLK | Jn.6 |
| U5, U6 | LRCLK | Jn.7 |
| U7, U8 | LRCLK | Jn.8 |
| U9, U10 | TXD0–15 | Jn.9 |
| U11, U12 | Jn.10 (+100 кОм к GND) | MIC0–15 → ПЛИС |
| U13 | BCLK, LRCLK, MON_SD, CAL | U31 (BCK, LRCK, DIN), J17 (BCLK, LRCLK), CAL → ПЛИС |

Все 74LVC244: VCC = 3V3_LOGIC, ~OE = GND, 100 нФ у каждого корпуса; входы допускают 5 В.

### Монитор наушников (на плате, без отдельных модулей)

| Поз. | Тип | Подключение |
|---|---|---|
| U31 | PCM5102A (TSSOP-20) | BCK, LRCK, DIN — от U13; SCK — GND (без MCLK, внутренний PLL); FMT — GND (I2S); XSMT — 3.3 В; FLT, DEMP — GND; обвязка LDO и накачки заряда — по типовой схеме даташита |
| U32 | TDA1308 (SO-8), питание 5 В | вход — LOUT/ROUT U31 через 1 мкФ; смещение — делитель 2 × 10 кОм + 10 мкФ; выходы — через 220 мкФ на J26, J27 |
| J26, J27 | гнёзда 3.5 мм, стерео | параллельно: левое ухо — луч приёма 0, правое — луч 1 |

**Регулятор громкости не нужен:** громкость лучей приёма задаётся весами в ПЛИС
(`dpaa_ctl.py`, пульт на планшете). TDA1308 нужен только как «силовой» каскад:
выход PCM5102A — линейный, он рассчитан на нагрузку от 1 кОм, а у наушников 16–32 Ом.

### Питание

| Поз. | Тип | Назначение |
|---|---|---|
| J18 | гнездо 5.5/2.1 мм | вход 5 В от G1 |
| Q1 | P-MOSFET ≥ 8 А, ≤ 20 мОм (AO4407A) | защита от переполюсовки |
| D1 | SMBJ5.0A | защита от выбросов |
| C10 | 1000 мкФ 10 В + 10 мкФ | накопитель |
| F1–F4 | PTC 1.5 А (1812) | по одному на группу из 4 элементов |
| U20 | AP2112K-3.3 | 3.3 В логики |
| U21 + FB1 | AP2112K-3.3 + феррит 600 Ом | отдельное чистое 3.3 В микрофонам (помехи усилителей класса D не попадают в приём) |
| LED1, LED2 | + 1 кОм | индикация 5 В и 3.3 В |

### Прочие разъёмы

J17 — RJ45 (зонд), J19–J24 — штыревые 2×6 (PMOD), J25, J28 — штыревые 1×3 (ESP32 и
резервный UART), SW1 — кнопка «тест». Раскладка контактов — [wiring.md](wiring.md).

## 3. Калибровочный зонд — готовые модули

| Поз. | Что | Подключение |
|---|---|---|
| — | готовая плата-переходник RJ45 с винтовыми клеммами | кабель CAT5 3 м от J17 |
| A22 | модуль ICS-43434 (такой же, как в элементах) | VDD, GND, SCK, WS, SD, L/R — провода Dupont в клеммы переходника |

Раскладка кабеля (T568B): пара 1–2 — BCLK/GND, 3–6 — LRCLK/GND, 4–5 — 3.3 В/3.3 В,
7–8 — SD/GND. Буферов на стороне зонда нет; если на 3 м появятся сбои, укоротите кабель
до 1.5–2 м.

## 4. Риски упрощённой схемы и что проверить первым делом

* **Такты по проводам Dupont без буфера на элементе.** На 3.125 МГц при длине до 40 см
  это обычно работает, но фронты могут «звенеть». Проверка: один элемент на самом
  длинном проводе, команды `peaks` и `elements`. Если есть сбои — укоротить провода,
  держать жгут элемента вместе (земли рядом с тактами) или поставить ферритовую бусину
  на провод BCLK.
* **Питание 5 В по одному проводу Dupont** — рассчитано на умеренную громкость
  (≤ 0.5 Вт на элемент); на максимальной громкости провод греется.
* Порядок выводов модулей — по надписям на плате модуля.
* Ключи шлейфов PMOD — одинаковая ориентация на обоих концах.
