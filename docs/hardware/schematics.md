# Схемы плат (теоретическая проработка)

Три платы собственной разработки: **модуль элемента** (×16 + запас), **распределительная
плата** (×1) и **калибровочный зонд** (×1). Ниже — принципиальные схемы в виде таблиц
соединений (по ним схема переносится в KiCad один к одному) и обоснование номиналов.
Все логические сигналы — LVCMOS 3.3 В.

---

## 1. Модуль элемента «ППМ» (16 шт. + 2 запасных)

Аналог приёмопередающего модуля ЦАФАР: цифровой вход → звук, звук → цифровой выход.

```
             J1 (IDC 2x5, к распределительной плате)
   +5V ──┬── 1,2 ──────────────────────────────┬──────────────┐
         │                                      │              │
        C1 220µF  C2 10µF  C3 100nF           FB1 (феррит)     │
         │                                      │              │
   GND ──┴── 3,5,7,9                         U2 AP2112K-3.3    │
                                               │ 3V3_EL        │
                                  C4 1µF ── C5 10µF ── C6 100nF│
                                               │               │
   BCLK ─── 4 ──[U3 74LVC1G17]──R3 22Ω──┬── A2.BCLK   A1.SCK   │
   LRCLK ── 6 ──[U4 74LVC1G17]──R4 22Ω──┼── A2.LRC    A1.WS    │
   TXD ──── 8 ───────────────────────────┴─ A2.DIN             │
   RXD ──── 10 ──R5 33Ω──── A1.SD                              │
                                                               │
   A2: модуль MAX98357A   VIN ← +5V ───────────────────────────┘
                          GAIN → VIN (усиление 6 дБ)
                          SD — не подключать (по умолчанию модуль включён)
                          OUT+ / OUT− → J2 → динамик LS1
   A1: модуль INMP441     VDD ← 3V3_EL,  L/R → GND (левый слот),  GND
```

### Таблица соединений

| Цепь | Соединения |
|---|---|
| +5V | J1.1, J1.2, C1+, C2, C3, FB1.1, A2.VIN, A2.GAIN |
| GND | J1.3, J1.5, J1.7, J1.9, C1−, C2…C6, U2.GND, U3.GND, U4.GND, A1.GND, A1.L/R, A2.GND |
| VIN_LDO | FB1.2, U2.IN, U2.EN (вход разрешения — к входу LDO), C4 (1 мкФ) |
| 3V3_EL | U2.OUT, C5 (10 мкФ), C6 (100 нФ), U3.VCC, U4.VCC, A1.VDD |
| BCLK_IN | J1.4 → U3.A (вход триггера Шмитта), R1 100 кОм → GND |
| LRCLK_IN | J1.6 → U4.A, R2 100 кОм → GND |
| BCLK_EL | U3.Y → R3 22 Ом → A2.BCLK, A1.SCK |
| LRCLK_EL | U4.Y → R4 22 Ом → A2.LRC, A1.WS |
| TXD | J1.8 → A2.DIN |
| RXD | A1.SD → R5 33 Ом → J1.10 |
| SPK± | A2.OUT+ → J2.1, A2.OUT− → J2.2 (JST-XH 2 контакта) → LS1 |

### Перечень элементов модуля

| Поз. | Номинал / тип | Корпус | Назначение |
|---|---|---|---|
| J1 | Вилка IDC 2×5 с ключом, 2.54 мм | THT | шлейф к распределительной плате |
| J2 | JST-XH 2 контакта | THT | динамик |
| A1 | модуль INMP441 (гнёзда 1×6) | — | микрофон |
| A2 | модуль MAX98357A (гнёзда 1×7) | — | ЦАП + усилитель |
| U2 | AP2112K-3.3 (или MCP1700-3302) | SOT-23-5 | отдельное чистое 3.3 В для микрофона и буферов |
| U3, U4 | 74LVC1G17 (буфер с триггером Шмитта) | SOT-23-5 | восстановление фронтов тактов после шлейфа |
| FB1 | феррит 600 Ом @ 100 МГц | 0805 | развязка LDO от помех усилителя класса D |
| C1 | 220 мкФ 10 В, low-ESR | радиальный | пиковые токи усилителя |
| C2, C5 | 10 мкФ X5R | 0805 | |
| C3, C6 | 100 нФ | 0603 | |
| C4 | 1 мкФ | 0603 | вход LDO |
| R1, R2 | 100 кОм | 0603 | определённый уровень при отключённом шлейфе |
| R3, R4 | 22 Ом | 0603 | согласование короткой линии к двум нагрузкам |
| R5 | 33 Ом | 0603 | последовательное согласование линии данных микрофона |

### Почему так

* **Отдельный LDO для микрофона**: усилитель класса D дёргает шину 5 В импульсами
  ~300 кГц; LDO с ферритом даёт микрофону чистое питание (PSRR), иначе помеха
  попадёт в приём.
* **Буферы Шмитта на тактах**: шлейф 0.5 м с 16 нагрузками в сумме даёт медленные
  фронты и «звон»; один 74LVC1G17 на модуль гарантирует чистый фронт и для усилителя,
  и для микрофона. Данные TXD не буферизуются — их защёлкивают по чистому фронту BCLK.
* **Контакты шлейфа чередуются с GND** (порядок жил: 5V, 5V, GND, BCLK, GND, LRCLK,
  GND, TXD, GND, RXD) — каждый сигнал идёт рядом со своим «обратным» проводом.
* **Размер платы ≤ 36 мм по ширине** (шаг решётки 40 мм), высота ~80 мм; модуль
  стоит за панелью, микрофон — отверстием к панели (проверьте, с какой стороны у вашего
  модуля INMP441 звуковое отверстие: у большинства — снизу, через плату), между
  микрофоном и корпусом динамика — поролоновая прокладка.

## 2. Распределительная плата

Связывает ULX3S с 16 модулями: размножает такты, буферизует все линии (защита выводов
ПЛИС от статики и «горячего» подключения шлейфов), раздаёт питание 5 В с предохранителями,
несёт ЦАП наушников и разъём калибровочного зонда.

```
 ULX3S J1/J2 (2 шлейфа 40 жил)                 16 x IDC 2x5 к модулям
 gp0  BCLK ──┬─[U1 74LVC244]─8x 33Ω──────────► J1..J8   BCLK
             └─[U2 74LVC244]─8x 33Ω──────────► J9..J16  BCLK
 gp1  LRCLK ─┬─[U3 74LVC244]─8x 33Ω──────────► J1..J8   LRCLK
             └─[U4 74LVC244]─8x 33Ω──────────► J9..J16  LRCLK
 gp2..gp9  TXD0..7 ──[U5 74LVC244]─33Ω───────► J1..J8   TXD
 gp10..17  TXD8..15 ─[U6 74LVC244]─33Ω───────► J9..J16  TXD
 gn0..7   ◄─33Ω──[U7 74LVC244]◄── 100k↓ ─────  J1..J8   RXD
 gn8..15  ◄─33Ω──[U8 74LVC244]◄── 100k↓ ─────  J9..J16  RXD
 gp18 MON_SD ─┐
 gp0/gp1 ─────┼─[U9 74LVC244]──► A4 PCM5102A (BCK, LRCK, DIN) → A5 усилитель → 2 гнезда 3.5 мм
              └────────────────► J17 RJ45 зонд (BCLK, LRCLK)
 gn16 CAL ◄───────[U9]◄───────── J17 RJ45 зонд (SD)

 +5V (J18, БП 5 В 6 А) → Q1 (защита от переполюсовки) → D1 TVS → C 1000 µF
      → F1..F4 (PTC 1.5 А) → группы по 4 модуля;  → U10 AP2112K-3.3 → 3V3_HUB (буферы)
 GND общий с ULX3S через шлейфы (все нечётные контакты GND на обоих 40-жильных шлейфах)
```

### Таблица соединений (сигналы)

| Сигнал ULX3S | Буфер | Выходы | Куда |
|---|---|---|---|
| gp0 (BCLK) | U1: все 8 входов A1–A8 соединены | Y1–Y8 → R 33 Ом | J1–J8, контакт 4 |
| gp0 (BCLK) | U2: входы A1–A8 | Y1–Y8 → R 33 Ом | J9–J16, контакт 4 |
| gp1 (LRCLK) | U3 | Y1–Y8 → R 33 Ом | J1–J8, контакт 6 |
| gp1 (LRCLK) | U4 | Y1–Y8 → R 33 Ом | J9–J16, контакт 6 |
| gp2…gp9 (TXD0–7) | U5 A1–A8 | Y → R 33 Ом | J1–J8, контакт 8 |
| gp10…gp17 (TXD8–15) | U6 A1–A8 | Y → R 33 Ом | J9–J16, контакт 8 |
| J1–J8 контакт 10 (RXD) | U7 A1–A8 (+100 кОм на GND) | Y → R 33 Ом | gn0…gn7 |
| J9–J16 контакт 10 | U8 A1–A8 (+100 кОм на GND) | Y → R 33 Ом | gn8…gn15 |
| gp0, gp1, gp18 | U9 A1–A3 | Y1–Y3 | A4.BCK, A4.LRCK, A4.DIN |
| gp0, gp1 | U9 A4–A5 | Y4–Y5 → R 33 Ом | J17 (зонд): BCLK, LRCLK |
| J17 SD зонда | U9 A6 (+100 кОм на GND) | Y6 → R 33 Ом | gn16 |
| — | U9 A7, A8 | не используются, входы на GND | |

Все 74LVC244: VCC = 3V3_HUB, ~OE1 = ~OE2 = GND, 100 нФ у каждого корпуса. Вход
74LVC244 допускает 5 В — дополнительная защита ПЛИС. Если какой-то вывод ULX3S
окажется неудобен, назначение переносится правкой `top_ulx3s.v` — RTL от этого не меняется.

### ЦАП наушников (A4, модуль PCM5102A)

| Вывод модуля | Подключение | Смысл |
|---|---|---|
| VIN | +5V (у модуля свой LDO) | |
| BCK / LRCK / DIN | U9 Y1 / Y2 / Y3 | I2S от ПЛИС, 64·fs, внутренний PLL |
| SCK | GND | работа без MCLK |
| FMT | GND | формат I2S |
| XSMT | 3V3 | звук не заглушён |
| FLT, DEMP | GND | стандартный фильтр, без деэмфазиса |
| LOUT/ROUT | → A5 (усилитель наушников с регулятором громкости) | левое ухо — луч приёма 0, правое — луч 1 |

### Питание

| Поз. | Тип | Назначение |
|---|---|---|
| J18 | гнездо 5.5/2.1 мм или клеммник на 10 А | вход 5 В |
| Q1 | P-MOSFET ≥ 8 А, Rds(on) ≤ 20 мОм (например, AO4407A) | защита от переполюсовки |
| D1 | SMBJ5.0A | защита от выбросов |
| C10 | 1000 мкФ 10 В + 10 мкФ | общий накопитель |
| F1–F4 | PTC 1.5 А удержание (1812) | по одному на группу из 4 модулей |
| U10 | AP2112K-3.3 | 3.3 В для буферов (ток < 50 мА) |
| LED1, LED2 | + R 1 кОм | индикация 5 В и 3.3 В |

ULX3S питается от своего USB (ноутбук или зарядник) — так плату ПЛИС нельзя
повредить ошибкой в силовой части.

## 3. Калибровочный зонд

Эталонный микрофон на стойке в 2–3 м от решётки: измеряет задержку и уровень каждого
канала и позволяет автоматически выровнять решётку (аналог встроенного контроля ФАР).

| Поз. | Тип | Подключение |
|---|---|---|
| J1 | RJ45 | пары: 1-2 BCLK/GND, 3-6 LRCLK/GND, 4-5 +5V/+5V, 7-8 SD/GND |
| U1 | AP2112K-3.3 | +5V → 3V3_P |
| U2, U3 | 74LVC1G17 | восстановление BCLK и LRCLK |
| A1 | INMP441 (L/R = GND) | SCK ← U2, WS ← U3, SD → 33 Ом → J1 |

Кабель CAT5 (витые пары) 3 м — на 3 МГц без проблем.

## 4. Что проверить при переносе в KiCad

* Физические номера контактов gp/gn на разъёмах ULX3S — по схеме вашей ревизии платы
  (см. [pinout.md](pinout.md)).
* Цоколёвку модулей MAX98357A и INMP441 конкретного продавца (у клонов порядок выводов
  на гребёнке бывает разным).
* Ширину модуля элемента ≤ 36 мм и положение отверстия микрофона.
* Ключи разъёмов IDC: одинаковая ориентация на всех модулях — иначе +5 В попадёт на сигналы.
